## Project Summary

I implemented a mini coding agent using Python, Ollama, and the `llama3.1:8b` model.

The agent supports three tools:
- `list_files`
- `read_file`
- `run_tests`

The project includes file access restrictions, user approval before running tests, and a maximum of 20 agent steps.
